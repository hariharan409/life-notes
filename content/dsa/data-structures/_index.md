## **1. Linear Data Structures**

| Data Structure | Description |
|---|---|
| Array | Fixed-size collection of elements stored in contiguous memory |
| Dynamic Array (Vector, ArrayList) | Resizable array that grows automatically |
| Singly Linked List | Chain of nodes where each node points to the next |
| Doubly Linked List | Chain of nodes with pointers to both next and previous nodes |
| Circular Linked List | Linked list where the last node points back to the first |
| Stack | LIFO structure — last element added is the first removed |
| Simple Queue | FIFO structure — first element added is the first removed |
| Circular Queue | Queue where the rear connects back to the front |
| Priority Queue | Queue where elements are dequeued based on priority |
| Deque (Double-Ended Queue) | Queue that supports insert and delete at both ends |

## **2. Non-Linear Data Structures**

### **Trees**

| Data Structure | Description |
|---|---|
| Binary Tree | Tree where each node has at most two children |
| Binary Search Tree (BST) | Binary tree with left < node < right ordering |
| AVL Tree | Self-balancing BST with height difference of at most 1 |
| Red-Black Tree | Self-balancing BST using color properties to maintain balance |
| B-Tree | Multi-way balanced tree used in databases and file systems |
| B+ Tree | B-Tree variant where all values are stored in leaf nodes |
| Heap (Min Heap, Max Heap) | Complete binary tree where parent is always min or max |
| Trie (Prefix Tree) | Tree for storing strings character by character |
| Segment Tree | Tree for efficient range queries and point updates |
| Fenwick Tree (Binary Indexed Tree) | Space-efficient tree for prefix sum and range queries |
| N-ary Tree | Tree where each node can have up to N children |

### **Graphs**

| Data Structure | Description |
|---|---|
| Directed Graph | Graph where edges have a direction (one-way) |
| Undirected Graph | Graph where edges have no direction (two-way) |
| Weighted Graph | Graph where edges carry a numeric weight or cost |
| Unweighted Graph | Graph where all edges are treated equally |
| Cyclic Graph | Graph that contains at least one cycle |
| Acyclic Graph | Graph with no cycles |
| DAG (Directed Acyclic Graph) | Directed graph with no cycles, used in scheduling and DP |

## **3. Hash-Based Structures**

| Data Structure | Description |
|---|---|
| Hash Table | Array-based structure using a hash function for fast access |
| Hash Map | Key-value store with average O(1) insert, delete, and lookup |
| Hash Set | Collection of unique keys with average O(1) membership test |

## **4. Specialized Data Structures**

| Data Structure | Description |
|---|---|
| Disjoint Set (Union-Find) | Tracks elements partitioned into non-overlapping sets |
| Bloom Filter | Probabilistic structure for fast set membership queries |
| Skip List | Layered linked list for fast search, insert, and delete |
| Suffix Tree | Tree of all suffixes of a string for fast pattern matching |
| Suffix Array | Sorted array of all suffixes for space-efficient string search |
